# 0008. English for every file, documentation included

- **Status:** accepted (deviation from the specification)
- **Date:** 2026-11-06

## Context

The specification asked for code in English and the documentation in Brazilian Portuguese for a
Brazilian audience. The repository is public.

## Decision

Everything committed is in English: code, comments, commits, documentation and the specification
itself (translated to `docs/spec.md`). Live presentations can still be given in Portuguese.

## Consequences

- One language to search and maintain; readable by anyone who finds the repository.
- The audience reads technical English, which is already the case for the tools' own documentation.
